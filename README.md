# 閉館5分前の図書館

閉館直前の図書館で、本としおりをめぐる選択をする短い分岐ノベルです。

公開URL: https://koseiomura-beep.github.io/tyrano_sample/

選択肢をクリックして進みます。GOOD、NORMAL、LATE、FORGOTの4種類の結末があり、どの結末からも最初に戻れます。

## 追加した内容

- docs/data/scenario/first.ks: オリジナルの文章と分岐
- docs/data/bgimage/library.svg、counter.svg、rain.svg: 自作の背景
- docs/game.css: 読みやすい表示と選択肢の装飾
- Config.tjs: タイトルとプロジェクト識別名

この演習で新規作成した文章・SVG背景・CSSはCC0とします。フレームワークと同梱素材の権利表示は以下の元リポジトリの記載に従います。元の写真素材はこのゲーム内では使用していません。
